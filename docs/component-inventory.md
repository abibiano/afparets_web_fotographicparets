# Component Inventory — FOTOgraphic Parets

Hugo does not use a component framework (React, Vue, etc.). "Components" here means reusable Hugo templates: **partials**, **shortcodes**, and **layout templates**.

---

## Page Layout Templates

Located in `layouts/`. These are the top-level rendering templates for each page type.

### `layouts/index.html` — Homepage
**Used for:** `/` (root)
**Structure:**
- Hero section (badge + title + subtitle + description + CTA buttons)
- "What is FOTOgraphic?" featured card (content from `_index.md`)
- Highlights grid (3 cards: Program, Contest, About — data from frontmatter)

**Data sources:**
- `{{ .Params.hero.* }}` — hero content from `content/_index.md` frontmatter
- `{{ .Params.highlights }}` — feature cards array from frontmatter
- `{{ .Content }}` — body content of `_index.md`

---

### `layouts/_default/baseof.html` — Base Document Shell
**Used for:** Every page (other templates "fill" its blocks)
**Structure:**
- `<html lang="{{ .Language.Lang }}">` — sets Catalan language attribute
- Partial: `head.html`
- `<a href="#main-content">` skip link (accessibility)
- Partial: `header.html`
- `<main id="main-content">` — page-specific content block
- Partial: `sponsors.html`
- Partial: `footer.html`

---

### `layouts/_default/single.html` — Generic Single Page
**Used for:** Any single-content page without a section-specific template
**Pages:** `concurso`, `quienes-somos`, `exposiciones-fotographic`, `guia`, `politica-privacidad`
**Structure:**
- Page title (`<h1>`)
- Optional `.Description` subtitle
- `.Content` — markdown body with `.content-styles` CSS class

---

### `layouts/_default/list.html` — Generic List Page
**Used for:** Any section index without a section-specific template
**Structure:**
- Page title and description
- `.Content` — section intro
- Grid of child pages as Bootstrap cards (title + description)

---

### `layouts/ponencias/list.html` — Program / Lectures List
**Used for:** `/ponencias/` — the event program page
**Structure:**
- Page title and description
- `.Content` — intro text
- Injects `schedule` component with agenda data from `$.Site.Data.agenda`
- Lists child pages (speaker cards)

**Note:** Passes `data/agenda/2025.yaml` to the schedule component.

---

### `layouts/ponencias/single.html` — Speaker Detail Page
**Used for:** `/ponencias/danny-vela/` and future speaker pages
**Structure:**
- Speaker name (title)
- Session metadata: schedule time, participants count, moderator name
- Speaker biography (`.Content`)
- Image carousel of event photos (using `image-carrousel` shortcode logic)

**Frontmatter fields consumed:**
- `schedule` — session time slot
- `participants` — number of participants
- `moderator` — session moderator name

---

### `layouts/404.html` — 404 Error Page
**Used for:** Page not found errors
**Structure:** Minimal error message page, includes base partials.

## Partial Components

Located in `layouts/partials/`. These are reusable fragments included with `{{ partial "name.html" . }}`.

### `partials/head.html` — HTML Head
**Included in:** `baseof.html`
**Responsibilities:**
- Meta charset, viewport
- SEO: title, description, canonical URL
- Open Graph tags (og:title, og:description, og:image, og:url, og:type)
- SCSS compilation pipeline: `resources.Get → toCSS → postCSS → minify → fingerprint`
- `<link rel="stylesheet">` with fingerprinted URL

**Key Hugo pipeline:**
```
resources.Get "scss/main.scss" | toCSS | postCSS | minify | fingerprint
```

---

### `partials/header.html` — Sticky Navigation Bar
**Included in:** `baseof.html`
**Responsibilities:**
- Bootstrap `navbar navbar-expand-lg sticky-top` structure
- Brand logo: resized to 60px height via Hugo image processing
- Navigation menu from `site.Menus.main` (auto-generated by Hugo from sections via `sectionPagesMenu`)
- Dropdown support via Bootstrap JS

---

### `partials/footer.html` — Footer
**Included in:** `baseof.html`
**Responsibilities:**
- Copyright line with dynamic year
- Social links: Facebook, website, email (using SVG icon images from `assets/img/icons/`)
- Privacy policy link
- Bootstrap bundle JS (from `node_modules` mount, with SRI integrity hash, fingerprinted)

---

### `partials/sponsors.html` — Sponsors & Partners Display
**Included in:** `baseof.html` (between main content and footer)
**Data source:** `{{ $.Site.Data.sponsors }}`
**Responsibilities:**
- Renders two sections: Organizers and Partners
- Parses `width`/`height` fields in YAML (format: `"NxM"`) to extract separate width/height values
- Applies Hugo `.ImageFit` processing with fingerprinting on each logo
- Responsive Bootstrap grid layout for logo gallery

**YAML fields consumed per sponsor:**
```yaml
- name: "Sponsor Name"
  logo: "img/logos/filename.png"
  url: "https://..."
  height: "60"       # optional, for display height constraint
  width: "200x60"    # optional, parsed as widthxheight
```

---

### `partials/components/schedule.html` — Event Schedule
**Included in:** `layouts/ponencias/list.html`
**Data source:** `data/agenda/2025.yaml` (passed as a variable)
**Responsibilities:**
- Renders a timed schedule list/table
- Shows: time slot, activity title, description
- Handles multi-day or single-day agenda structures
- Graceful fallback if agenda data is missing

**2025 Schedule:** 13 activities from 09:30 to 20:00, November 29, 2025

## Shortcodes

Located in `layouts/shortcodes/`. Used in Markdown content files with `{{< shortcode-name params >}}` syntax.

### `image-fill` — Crop & Fill Image
```
{{< image-fill src="path/to/img.jpg" width="800" height="600" alt="Description" >}}
```
- Uses Hugo's `.Fill` method: crops to exact dimensions
- Fingerprints output URL
- Outputs: `<img src="..." alt="...">`

### `image-fit` — Scale & Fit Image
```
{{< image-fit src="path/to/img.jpg" width="800" height="600" alt="Description" >}}
```
- Uses Hugo's `.Fit` method: scales proportionally within bounds
- Fingerprints output URL

### `image-resize` — Resize Image
```
{{< image-resize src="path/to/img.jpg" width="800" alt="Description" >}}
```
- Uses Hugo's `.Resize` method: resize by one dimension (preserves aspect ratio)
- Fingerprints output URL

### `image-carrousel` — Carousel Image
```
{{< image-carrousel src="path/to/img.jpg" width="800" height="600" alt="Description" >}}
```
- Variant of `image-fit` specifically for use in Bootstrap carousel components
- Used in `ponencias/single.html` for displaying event session images

## SCSS Component Styles

Located in `assets/scss/styles.scss`. CSS classes mapped to UI sections:

| Class | Component | Description |
|-------|-----------|-------------|
| `.hero` | Hero section | Full-height banner with background, centered content |
| `.highlight-card` | Feature cards | Hover animation, icon display |
| `.content-styles` | Markdown content | Styles for rendered markdown (headings, lists, images) |
| `.schedule-*` | Schedule component | Table rows, time column, activity titles |
| `.sponsors-*` | Sponsors partial | Logo grid, section dividers |
| `.navbar` overrides | Header | Custom sticky behavior, scroll-triggered background change |
| Custom buttons | CTAs | Primary/secondary button variants |

## Data-Driven Sections

These sections are entirely data-driven (no hardcoded content in templates):

| Section | Data File | Template |
|---------|-----------|----------|
| Event agenda / schedule | `data/agenda/2025.yaml` | `partials/components/schedule.html` |
| Sponsors & partners | `data/sponsors.yaml` | `partials/sponsors.html` |

To update the event schedule or add sponsors, **only the YAML files need editing** — no template changes required.
